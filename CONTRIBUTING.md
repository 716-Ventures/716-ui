# Contributing

The project is in its specification phase. Discuss architecture or rendering dependencies before adding them. Useful early contributions include a reproducible native toolkit comparison and precise component reference contracts.

Keep controls independent of agentOS, providers and privileged actions. Implement shared native behavior rather than application-specific workflows. Each component contribution needs documented reference provenance, visual/interaction coverage and accessibility behavior. Do not claim tests ran unless their results are recorded.

Original contributions are provided under Apache-2.0. Preserve the licenses and attribution of incorporated third-party material. Never commit credentials, account data or generated application state.

Build and test commands will be documented alongside the first working implementation. There are no code build commands at this stage.

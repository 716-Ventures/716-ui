# Pinned Button, Input, Tabs and Checkbox browser harness

This developer-only harness bundles the actual checksum-verified `reference/button.tsx`, `reference/input.tsx` and `reference/tabs.tsx` and `reference/checkbox.tsx` with the pinned Zinc tokens, default Tailwind spacing/radius and Inter font files supplied by the tester. It does not reproduce the upstream website's global styles, theme generator or responsive application overrides. In particular, the unqualified light outline border inherits Tailwind's current-color default. Consumer-global border rules must be assessed separately.

Run `npm ci` in this directory, then set `REFERENCE_INTER_REGULAR`, `REFERENCE_INTER_MEDIUM`, `REFERENCE_INTER_SEMIBOLD` to the exact font files used for native qualification and `REFERENCE_INTER_LICENSE` to their copyright/license notice. Run `npm run build`. The ignored `test-output/reference-browser` directory contains the bundled page, source/font provenance and preserved upstream/font notices. Serve that directory on localhost for browser inspection; close the server and tab afterward. Fonts, generated output and dependencies are not committed.

The 2026-10-10 local in-app browser inspection exercised activation, keyboard focus transfer, disabled semantics and light/dark switching. Computed natural defaults were 36px height, 6px radius, 14px/500 Inter, 8px vertical and 16px horizontal padding, 150ms transitions, and 0.5 disabled opacity. Natural text-only widths were 78.8203125, 103.015625, 79.359375, 69.859375 and 107.3984375 CSS pixels for default, secondary, outline, ghost and destructive respectively. The allocated row measured 190×40 CSS pixels. Light and dark screenshots were inspected during the run. Focus paint, hover/press trajectories, frame timing, full pixel comparisons, other components and other browser engines remain unqualified by this inspection.

The native library's existing 50 painted Button state endpoints are a separate GTK check. Native destructive contrast, stronger borders and native focus presentation remain documented differences. Native background motion now uses the observed reference default of 150ms cubic-bezier(0.4, 0, 0.2, 1). The Motion observer records actual pointer enter/leave computed-style samples over animation frames; the local browser inspection exercised light entry/reversal and dark entry. Frame callback offsets are clipped at zero for an event arriving after the current frame timestamp. Neither this harness nor derived color expectations establish full shadcn parity. It adds no browser dependency to the Rust library or native consumers.

The measured natural widths and 36px height for the five default text-only variants are retained in `reference/button-metrics.json`. Native `button-metrics` checks those border-box dimensions within 1px using Inter Medium 14px; GTK content-box dimensions are recorded separately. These measurements exclude upstream website globals and do not qualify other sizes or icons.

The Input section imports the checksum-verified upstream component unchanged. `reference/input-observation.json` records the scoped desktop observation, actual controlled Unicode editing, keyboard focus and disabled checks. It does not establish full input parity, mobile styles, invalid/file variants or physical timing.

The default horizontal Tabs fixture uses the unchanged pinned component and controlled page selection. `reference/tabs-observation.json` records actual light/dark styles and ArrowRight wrap/disabled-skip, End and Home activation checks. The observed strip is 36px high with 3px padding and 8px radius; triggers are 29px high with 14px/500 Inter. Native Tabs parity, vertical/line variants, RTL, assistive announcements and frame timing remain unqualified. This observation does not change the native API or release tag.

Checkbox imports the pinned upstream source unchanged, with lucide-react 0.474.0 restricted to this developer harness; its license is copied into generated output. `reference/checkbox-observation.json` records actual default checked/unchecked geometry, light/dark paint, Space/pointer activation and disabled state. Invalid/indeterminate states, focus paint, assistive announcements, motion trajectories and native parity remain unqualified.
